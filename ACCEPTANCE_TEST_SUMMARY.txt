REMAINING ACTIONS FOR PRODUCTION
================================================================================

1. INSTALL POSTGRESQL
   - Download from https://www.postgresql.org/download/
   - Create database: steg_monitoring
   - Create user: postgres or custom user

2. CONFIGURE ENVIRONMENT VARIABLES
   set DB_URL=jdbc:postgresql://localhost:5432/steg_monitoring
   set DB_USERNAME=postgres
   set DB_PASSWORD=your-secure-password
   set JWT_SECRET=long-random-secure-string-minimum-32-chars

3. START WITH POSTGRESQL
   java -jar target/smart-monitoring-backend-0.0.1-SNAPSHOT.jar \
     --spring.profiles.active=prod

4. VERIFY PERSISTENCE
   - Create test record via API
   - Stop application
   - Restart application
   - Verify test record still exists

5. PERFORM LOAD TESTING
   - Use Apache JMeter or similar
   - Test 100+ concurrent users
   - Verify connection pooling works
   - Check database query performance
